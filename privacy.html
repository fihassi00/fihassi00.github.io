Privacy Policy

Channels Automation · last updated 30 September 2026

What this application is

Channels Automation is a private tool used only by its owner to upload videos to the owner's own YouTube channels. It is not available to other users.

Google and YouTube data it uses

With the owner's authorisation (OAuth, scope youtube.force-ssl), it uses the YouTube Data API to:

  • read the authorised channel's identity (id, title, handle, video count) to make sure a video goes to the right channel;
  • upload videos and set their title, description and privacy status on that channel.

It does not read comments, subscribers, watch history or any other personal data.

Storage and sharing

Authorisation tokens are stored only on the owner's own computer. No Google user data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
